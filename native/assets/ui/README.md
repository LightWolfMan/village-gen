# Ícones do HUD

Seleção de 12 SVGs do Lucide, versão 0.468.0, obtidos de https://github.com/lucide-icons/lucide/tree/0.468.0/icons.
Licenças e atribuições do conjunto estão em `LICENSE-lucide` (ISC e MIT para os ícones derivados do Feather).

Adaptação local: dimensões de rasterização 48 × 48 e traço branco para tintura pelos temas do Godot. As formas originais foram preservadas. Ícones são importados e empacotados com o executável; o aplicativo não faz downloads. O HUD utiliza nomes curtos sob os símbolos e dicas descritivas, sem depender somente da cor para indicar a ferramenta.
